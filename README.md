# Block Destroyer (Educational)

A Manifest V3 extension for Chrome and Brave called **Block Destroyer**. When enabled (switch set to ON), it removes common selection/copy restrictions, disables links, and prevents the selection of photographic items triggered by clicking. Double-clicking an image starts an automatic download, using the filename specified in the URL; if the file already exists, the browser adds a number to the filename. The **View available options** button in galleries is preserved.

The **About** menu displays the author, Richard Multimedia, the manifest version, and the Help Donate link.

## Installing on Chrome or Brave

1. Open `chrome://extensions` in Chrome or `brave://extensions` in Brave/Chrome.
2. Enable **Developer mode**.
3. Select **Load unpacked** and choose this folder.
4. Open the desired page, click the extension icon, and turn the switch ON. Double-click an image to save it. Turn the switch OFF to restore links and interactions.

Access to the page is limited to the current tab (`activeTab`). The `downloads` permission saves files using the browser's download manager. The extension does not send or store any data. Changes are temporary and are removed when the page is reloaded. Internal browser pages and images served via `blob:` URLs are not supported.

# PT-PT

# Destruidor de Bloqueios

Extensão Manifest V3 para Chrome e Brave chamada **Destruidor de Bloqueios**. Ao ativar (switch em ON), remove bloqueios comuns de selecção/cópia, desativa links e interrompe a seleção de itens fotográficos acionada por clique. Um duplo clique numa imagem inicia a transferência automática, com o nome do ficheiro indicado no URL; se já existir, o navegador acrescenta um número. O botão **Ver opções disponíveis** nas galerias é preservado.

O menu **Sobre** apresenta o autor Richard Multimedia, a versão do manifesto e o link Help Donate.

## Instalar no Chrome ou Brave

1. Abra `chrome://extensions` no Chrome ou `brave://extensions` no Brave/Chrome.
2. Ative **Modo de programador**.
3. Escolha **Carregar expandida** e seleccione esta pasta.
4. Abra a página pretendida, clique no ícone da extensão e ligue o switch (ON). Faça duplo clique numa imagem para a guardar. Desligue o switch (OFF) para restaurar os links e as interações.

O acesso à página limita-se ao separador atual (`activeTab`). A permissão `downloads` guarda os ficheiros pelo gestor de transferências do navegador. A extensão não envia nem guarda dados. A alteração é temporária e desaparece ao recarregar a página. Páginas internas do navegador e imagens servidas por URL `blob:` não são suportadas.
